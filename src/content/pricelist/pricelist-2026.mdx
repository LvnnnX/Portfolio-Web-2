Daftar layanan pembuatan website yang aku tawarkan tahun ini — dari landing page sederhana sampai e-commerce custom. Disusun dengan range harga yang transparan supaya kamu tahu dapat apa di setiap tingkatnya, bukan sekadar nomor besar tanpa konteks.

## i. Micro-site / Landing Page

**Mulai dari Rp 100 rb – 1 jt**

Halaman tunggal yang fokus pada satu pesan — undangan digital, landing campaign, atau profil singkat yang harus jadi cepat.

### Catatan Transparan tentang Range Tier 01

- **Rp 100 rb – 300 rb** · Template-based, kustomisasi minimal (warna, teks, foto). Cocok untuk undangan digital sederhana, link-in-bio, landing event 1 hari.
- **Rp 400 rb – 700 rb** · Template + customization design ringan (layout adjust, animation, branding match).
- **Rp 800 rb – 1 jt** · Full custom design dari nol, struktur fleksibel, brand-aligned.

> Jujur dari awal supaya kamu dapat nilai sesuai budget — bukan ekspektasi salah.

### Yang termasuk di semua range

- Responsive mobile + desktop
- Form kontak / WhatsApp redirect
- Setup domain + hosting Cloudflare Pages
- 2× revisi minor
- Source code diserahkan

### Khusus Rp 800 rb ke atas

- Design custom dari nol (bukan template)
- Animation halus (CSS-only)
- Konsultasi visual identity awal

**Cocok untuk:** undangan digital, landing campaign event, micro-portfolio, profil singkat freelancer, link-in-bio premium.

## ii. Company Profile / Portfolio

**Mulai dari Rp 2 jt – 4 jt**

Website 3–5 halaman dengan design system yang konsisten. Cocok untuk yang sudah punya brand dan butuh kehadiran serius di web.

- 3–5 halaman (Home, About, Services, Projects, Contact)
- Design system custom (tokens, tipografi, palette)
- Content management via Markdown / Notion
- Form kontak + integrasi email (Resend / EmailJS)
- SEO basics (meta tags, sitemap, OG image)
- Analytics (Plausible / Cloudflare)
- Domain + hosting setup
- 3× revisi

**Cocok untuk:** studio arsitek/desain, konsultan, agency kecil, freelancer profesional, brand UMKM yang serius.

---

## iii. Business Website + CMS

**Mulai dari Rp 4 jt – 8 jt**

Website yang bisa di-update sendiri oleh tim non-teknis, dengan blog, multi-bahasa, dan SEO yang serius.

- 6–12 halaman + dynamic routing
- Headless CMS (Sanity / Notion / Strapi) — admin bisa edit sendiri
- Blog / News section
- Search internal
- Multi-bahasa (Indonesia + English) opsional
- Newsletter signup (Resend / ConvertKit)
- SEO advanced + schema.org
- Performance audit (Lighthouse 95+)
- Training admin 1× sesi
- 4× revisi

**Cocok untuk:** bisnis menengah, restoran/villa butuh booking inquiry, brand dengan content rutin, lembaga pendidikan, NGO.

---

## iv. Custom Web App / E-commerce

**Mulai dari Rp 10 jt – 20 jt**

Aplikasi web custom dengan database, autentikasi, payment gateway, dan dashboard admin. Spec lengkap diserahkan sebelum coding.

- Custom multi-page application
- Auth (email + password / Google OAuth)
- Database (Supabase / Postgres) + Row Level Security
- Payment integration (Midtrans / Xendit)
- Admin dashboard + role-based access
- Email transactional (order confirmation, receipt)
- Storage (Cloudflare R2 / S3) untuk file/foto
- Spec triad delivered (SRS + CLAUDE.md + DESIGN.md)
- QA + UAT testing
- Garansi bug-fix 30 hari
- Training + dokumentasi
- 5× revisi

**Cocok untuk:** marketplace digital file, e-commerce kecil-menengah, SaaS MVP, sistem manajemen custom (booking, inventory, CRM kecil).

---

## v. Enterprise / Custom Scope

**Mulai dari Rp 25 jt+**

Untuk proyek dengan skala kompleks — multi-modul, integrasi berat, atau kebutuhan AI/ML. Konsultasi dulu, atau pakai retainer per bulan.

- Aplikasi multi-modul (HR + finance + operations)
- Integrasi ERP / accounting existing
- AI/ML feature (chatbot, recommendation, image processing)
- Real-time (WebSocket, live update)
- Mobile-first dengan progressive web app

## Cara Kerja

1. **Kontak Awal** via WhatsApp atau email — kasih tau scope kasar.
2. **Discovery Call** 30–45 menit, gratis. Bahas kebutuhan, anggaran, timeline.
3. **Quote + Kontrak** dikirim maksimal 2 hari kerja setelah discovery.
4. **DP + Kickoff** — proyek officially dimulai setelah DP masuk.
5. **Design Phase** — mockup interactive, revisi sampai approved.
6. **Development Phase** — weekly progress update via WhatsApp / email.
7. **UAT + Revisi Final** — kamu test dulu di staging URL.
8. **Pelunasan + Handover** — source code, akses hosting, dokumentasi.
9. **Garansi 30 Hari** — bug-fix gratis untuk masalah yang muncul setelah handover.
