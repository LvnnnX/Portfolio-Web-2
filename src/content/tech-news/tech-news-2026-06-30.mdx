## Cursor Rilis iOS App — AI Coding Agent Sekarang Bisa Jalan di Mana Saja

Anysphere, perusahaan di balik Cursor, baru saja launch Cursor for iOS yang memungkinkan developers run always-on cloud agents langsung dari iPhone. Seperti yang dilaporkan Digg via rangkuman thread Hacker News, app ini juga supports voice dictation buat background code generation. Itu artinya developer bisa dapat code suggestion tanpa harus buka laptop.

Aku pribadi sudah pakai Cursor sejak versi beta, dan fitur yang bikin jadi addict adalah aksesibilitas — nggak ribet, langsung works. Tapi sejauh ini tetap tethered ke desktop. Dengan iOS app, skenarionya berubah: kamu bisa review PR dari café, approve code suggestion dari mana aja, bahkan pair programming dari jauh pakai voice.

Untuk developer Indonesia yang banyak work remote atau freelance ke client overseas, ini alat produktivitas yang signifikan.risiko-nya: dependency makin dalam ke satu tool. Ketika Cursor menguasai flow kerja kita, switching cost jadi mahal.

## Google I/O 2026: Gemini 3.5 dan Antigravity Platform — Agent-First Era Resmi Dimulai

Google Developers Blog nge-post resumenya: Google resmi transisi dari AI yang "simply assists" ke agents yang bisa "independently navigate complex tasks across your entire workflow." Gemini 3.5 series launched, dan Antigravity — platform agent-first development mereka — di-upgrade dengan kapabilitas baru buat orchestrate dan build agents.

Yang menarik dari announcement ini adalah framing-nya. Google nggak cuma fokus ke model performance, tapi ke orchestration layer — artinya Google paham bahwa di 2026, bottleneck-nya bukan AI capability, tapi coordination antar agents. Buat developer, ini sinyal bahwa skill yangvaluable bukan cuma prompt engineering, tapi system design: gimana cara orchestrate multiple AI agents yang specialized.

Aku udah coba Antigravity preview bulan lalu, dan impresi pertama: steep learning curve tapi powerful. Kalau kamu developer Indonesia yang mau masuk space AI agent development, ini platform yang worth untuk diinvestigasi lebih dalam.

## Devin 2.2 Launch — AI Coding Agent yang Bisa Monitor Bug dan Handle Android Emulator

Cognition, perusahaan di balik Devin, release Devin 2.2 yang mereka klaim sebagai "the most important update to Devin since launch." Blog Cognition menjelaskan fitur baru: Devin sekarang bisa monitor bugs dan alerts, investigate dengan tools yang tersedia, connect related reports, dan open PR secara autonomous. Plus, Devin now natively builds, runs, and tests di Windows VMs, serta supports Android emulators untuk autonomous Android app development.

Dari semua update, yang paling bikin aku attentive adalah Auto-Triage. Dave Colwell, VP AI/ML di Tricentis, bilang bahwa "developers risk becoming the bottleneck" seiring agentic code accelerate delivery. Itu persis yang aku punya: kalau AI agent makin capable, skill set yang kita butuhkan berubah drastis. Dari writing code ke reviewing, orchestrating, dan verifying.

Untuk developer Indonesia yang fokus di mobile development, Devin Android emulator support adalah sinyal bahwa AI-generated mobile code quality sudah cukup mature untuk production consideration.

## Imbue Acquires Bun — AI Startup Makin Serius dengan Developer Tooling

CRN melaporkan bahwa Imbue, AI startup San Francisco yang specialize di tools buat AI coding agents, acquire Bun bulan lalu. Bun sendiri membantu developers run dan manage code lebih effectively. Bagi Imbue, akuisisi ini strategical: mereka mau enhance Sculptor — UI buat coding agents — dengan runtime yang lebih performant.

Ada angka menarik dari First Line Software: "Imbue acquired Bun, which helps developers run and manage codes more effectively." Tapi yang lebih significance dari berita ini adalah trend-nya: AI companies mulai vertical integrate ke developer tooling. Imbue nggak cuma mau build AI agent, mereka mau kontrol stack — dari AI reasoning sampai execution environment.

Aku nggak surprised dengan akuisisi ini. Dari perspektif developer Indonesia, ini artinya pilihan tooling kita makin dikurasi sama perusahaan AI. Kalau Imbue (atau entity yang acquire mereka ke depannya) decide untuk integrated approach, alternative tools mungkin bakal lose relevance.

## AI Sekarang Nulis 46% Code — Stats yang Bikin Aku tentang Skill Masa Depan

First Line Software publish analisis komprehensif: 92% US developers udah adopt alguma form of AI coding by early 2026. GitHub Copilot has 20 juta users dan deployed di 90% Fortune 100 companies. Angka paling mengejutkan: AI now generates 46% of code in files where Copilot is active — rising to 61% for Java. Cursor reached $500 million ARR dan $9.9 billion valuation.

Data-data ini aku catat karena mereka concrete, bukan speculation. Dari angka-angka ini, aku menarik dua kesimpulan: (1) AI coding bukan future, it's now. 46% itu udah signifikan, dan pertumbuhan ke 61% di Java menunjukkan trend yang accelerating. (2) Skill yang valued di pasar bakal shift: kemampuan untuk orchestrate AI, bukan menulis code dari scratch.

Tapi ada nuance yang sering di-ignore: percentage bukan quality indicator. AI generates banyak code, tapi nggak semua code itu good code. Yang masih: developer yang bisa evaluate, refactor, dan improve AI-generated code.

## Yang aku bawa pulang dari kelima berita ini

Ada satu benang merah yang aku lihat: **kita sedang di middle of a platform shift**. Cursor launch iOS, Google push agent orchestration, Devin improve autonomous capabilities — semuanya mengarah ke world where AI agents beroperasi secara continuous, integrated ke workflow kita, dan accessible dari anywhere. Angka 46% code generated by AI itu bukan hiperbola; itu real-time statistic yang harus kita account for.

Pertanyaan yang muncul di benakku: sebagai developer Indonesia, kita consumers atau participants di shift ini? Kebanyakan dari kita (termasuk aku) adalah heavy users of US-based AI tools — Cursor, Copilot, Claude, Gemini. Kita benefit dari tooling mereka, tapi kita tidak control infrastrukturnya. Ketika Imbue acquires Bun, ketika OpenAI builds custom chips, ada value creation yang terjadi di sana — dan kita mostly observers.

Yang aku think about juga: skill set kita perlu berevolusi. AI generating 46% code bukan threat; itu liberation dari boilerplate. Tapi liberation without direction is dangerous. Direction itu datang dari pemahaman business domain, system architecture, dan kemampuan untuk evaluate output — skill yang nggak bisa di-automate away.

Ini bukan analysis mendalam. Aku cuma developer yang kebetulan peduli sama arah industri ini. Tapi menurutku, tempat paling sehat untuk peduli adalah dengan menulis — atau setidaknya, membaca tulisan orang lain yang punya angle berbeda. Cheers buat yang udah baca sampai sini.
